# Keybindings (SUPER = Windows key)

| Keys | Action |
|---|---|
| SUPER + Enter | Terminal (Ghostty) |
| SUPER + Space | App launcher |
| SUPER + E / B / O | Files / Chromium / VS Code |
| SUPER + C | Clipboard history |
| SUPER + Q | Close window |
| SUPER + F / M | Fullscreen / Maximize |
| SUPER + V | Float window |
| SUPER + S | Toggle split direction |
| SUPER + G | Group (tabs) |
| SUPER + H J K L / arrows | Focus |
| SUPER + SHIFT + H J K L / arrows | Move window |
| SUPER + CTRL + H J K L | Resize |
| SUPER + 1…0 | Workspace 1…10 |
| SUPER + SHIFT + 1…0 | Move window to workspace |
| SUPER + Tab | Previous workspace |
| SUPER + ` | Scratchpad terminal |
| SUPER + SHIFT + S / Print / SUPER + Print | Screenshot region / screen / window |
| SUPER + , | Dismiss notifications |
| SUPER + SHIFT + , | Do Not Disturb |
| SUPER + Esc | Lock |
| SUPER + SHIFT + Esc | Power menu |
| SUPER + SHIFT + T | Theme picker |
| Alt + Shift  or  SUPER + ALT + Space | Switch EN / UA |
| SUPER + SHIFT + R | Reload Hyprland |
| SUPER + SHIFT + E | Log out |
| SUPER + drag (left / right mouse) | Move / resize |
| 3-finger swipe | Switch workspace |
